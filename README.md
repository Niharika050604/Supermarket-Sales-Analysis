# Supermarket Sales Analysis 🛒

An exploratory data analysis project on supermarket sales data, visualized using Power BI.

## 📁 Files in this Repository
| File | Description |
|------|-------------|
| `supermarket_sales.xlsx` | Raw sales dataset |
| `Practical - 2.pbix` | Power BI dashboard with visualizations |
| `Practical_2_word_doc.docx` | Written analysis and findings |
| `practical-2.pdf` | Problem statement / questions answered |

## 📊 Objective
To analyze supermarket sales data and extract actionable insights about revenue, product performance, and customer behavior.

## 🔍 Key Areas Explored
- Sales trends across product lines and branches
- Revenue breakdown by payment method and customer type
- Peak sales hours and days
- Gross income and profit margin analysis
